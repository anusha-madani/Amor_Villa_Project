AMOR VILLA WEBSITE

PROJECT DESCRIPTION:
Villa Amor is a front-end villa booking website designed as a semester project.  
This project focuses on basic UI/UX design for browsing villas and understanding booking layout concepts.  
It does not include backend functionality or real booking system.

---
TECHNOLOGIES USED:
- HTML5  
- CSS3  
- JavaScript (Basic)

FEATURES:
- Responsive homepage design  
- Villa listing layout  
- Image slider/banner  
- Navigation bar  
- Basic booking-style UI  
- About section  
- Contact section (frontend only)

PURPOSE OF PROJECT:
This project was created for learning and academic purposes to improve:
- Frontend development skills  
- Layout structuring  
- UI design understanding  
- Basic JavaScript usage  

⚠️ Note
This is only a frontend project. No real booking or database functionality is included.
